# 🎵 Яндекс.Музыка Голосовой и Текстовый Ассистент

Полнофункциональный голосовой и консольный ассистент для Яндекс.Музыки на базе локальной нейросети **Whisper**, синтеза речи **TTS** и официального API Яндекс.Музыки.

---

## 📦 Готовый установщик для переноса на другой ПК

Готовый файл установщика (не требует установки Python, Git или сторонних библиотек на целевом ПК):
```text
C:\Users\Reink\.gemini\antigravity\scratch\yandex_music_assistant\installer_output\YandexMusicAssistant_Setup.exe
```
Просто скопируйте файл **`YandexMusicAssistant_Setup.exe`** на флешку и запустите на любом компьютере с Windows 10/11. Установщик:
1. Установит полностью автономный изолированный runtime со всеми библиотеками.
2. Включит встроенную офлайн-модель Whisper (интернет для скачивания нейросетей не нужен).
3. Создаст ярлык на Рабочем столе и в меню Пуск.

## 🎤 Голосовое управление и Wake-Word

* **Триггер по умолчанию:** `Морсик`
* **Формат голосовой команды:**
  * «Морсик, включи Queen Bohemian Rhapsody»
  * «Морсик, включи исполнителя Король и Шут»
  * «Морсик, моя волна»
  * «Морсик, пауза» / «Морсик, дальше»
* **Смена триггера на лету:**
  * «Морсик, теперь тригер — Карлуша» (или «Морсик, смени триггер на Карлуша»)
  * Ассистент подтвердит смену голосом и сохранит новое имя в `settings.json`.
* **Запрос текущего триггера (Wake-word НЕ нужен):**
  * «Какой сейчас тригер?» / «Какой триггер?»
  * Ассистент сразу назовет активное имя голосом и выведет его в консоль.

## ⌨️ Ввод через терминал

Терминал активен одновременно с голосовым вводом:
* Для ввода текста **Wake-word не требуется**.
* Все распознанные голосовые команды также дублируются в терминале:
  `🎤 [Голос]: Морсик, включи 21 Pilots`
* Вы можете одновременно писать с клавиатуры любые запросы и команды (`пауза`, `дальше`, `громкость 80`, `какой триггер`, `Queen`).

## 🔊 Синтез речи (TTS)
* Использует офлайн-голос Windows (SAPI5, русский голос Ирина).
* Во время ответа ассистента музыка автоматически приглушается (ducking) до 15% и плавно возвращается обратно после ответа.
